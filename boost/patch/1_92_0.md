delete: the line
`<local-visibility>hidden`

in:
the `project ... : requirements ...` block near the top of the file (~line 28)

in the build files
- [histogram](https://github.com/boostorg/histogram/issues/425)
    - `build.jam`

apply:
```bash
sed -i '/<local-visibility>hidden/d' down/boost/1.92.0/libs/histogram/build.jam
```

to avoid build errors like

```yaml
error: No best alternative for .../libs/histogram/install-libraries-shared with ... <visibility>hidden ...
    no match: <local-visibility>hidden
    no match: <local-visibility>hidden <target-os>windows
    no match: <local-visibility>hidden <target-os>cygwin
```

-----
note:

histogram is header-only — this requirement doesn't do anything except break the install
step on any target-os other than windows/cygwin (Android included). Already fixed upstream
via PR #433, but that landed after the 1.92.0 tag was cut, so it still needs patching here.

see also:

[`<local-visibility>hidden` in `build.jam` creates problems when building Boost](https://github.com/boostorg/histogram/issues/425)
